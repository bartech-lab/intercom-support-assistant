# Domain map

Find the owning module and its tests before changing a behaviour. `test/tools/domain-map.test.js` fails when a source or test file is missing here or a link breaks.

Content scripts load in the order declared in `src/manifest.json`; `src/intercom-page-hook.js` runs alone in the MAIN world. `src/signatures-data.js` is generated by `tools/update-preview.js`.
